# Recursion Base Case Stack Overflow

This Python script demonstrates the concept of recursion in programming. It shows a factorial function with a clear base case and recursive step, and also illustrates how a lack of a base case can lead to a stack overflow error.

## Language

`python`

## How to Run

Save the code as `recursion_demo.py` and run it from your terminal using `python recursion_demo.py`.
